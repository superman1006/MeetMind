## 一、会议纪要

用户要求复刻 MeetMind 项目（LangGraph 驱动的多 Agent 协作系统）。经全员讨论，明确了各角色职责与交付物：

**核心链路**：意图路由 → 角色调度 → RAG 检索 → 讨论收敛。
**技术选型**：后端 LangGraph + FastAPI + PostgreSQL（pgvector+tsvector）+ ONNX 本地推理；前端 Vue3 + TypeScript + Vite + Tauri2。
**关键决策**：V1 砍掉自定义 Agent、实时协作、历史回放；SSE 流式返回讨论过程；每个 Agent 私有知识库隔离；max_iterations 硬限制防不收敛。
**总工时**：后端 9-13 人天，前端 10-15 人天，合计约 19-28 人天。

**待办**：前后端对齐 SSE 事件协议 schema 后并行开发；PM 需确认 HITL 审批交互细节、会话恢复策略、时区处理、模型热切换 loading 状态。

## 二、各 Agent 的工作

### 架构师

无

### 后端工程师

- 实现 LangGraph 状态图（意图路由 → 5 Agent 节点 → 收敛判断）
- 实现 RAG 管线：ONNX 嵌入 + pgvector/tsvector 双路召回 + cross-encoder 重排序
- 搭建 PostgreSQL schema（documents 表，含向量索引和全文索引）
- 实现 FastAPI 接口：SSE 流式讨论、同步讨论、知识库上传/查询
- ONNX 模型导出与启动预加载
- 反循环检查与 max_iterations 硬限制

### 前端工程师

- 搭建 Vue3 + TypeScript + Vite + Tauri2 项目骨架
- 实现 SSE 事件消费与流式渲染（MessageBubble + ToolCallPanel + CitationBadge）
- 实现 SessionSidebar（会话 CRUD）
- 实现 InputArea + ToolApprovalModal（HITL 审批）
- 实现 SettingsPanel（模型切换 / 用户记忆）
- 封装 JSON-RPC 客户端
- 与后端联调 SSE 事件协议

### 测试工程师

- 编写意图路由分类测试用例（开发需求/闲聊/空输入/中英混合）
- 编写 Agent 调度顺序与反循环测试用例
- 编写 RAG 检索测试用例（命中/无结果/多角色隔离）
- 编写异常场景测试用例（ONNX 加载失败/PG 断连/超长输入）
- 搭建自动化测试框架，覆盖意图路由+图流转+RAG 三条链路
- 人工探索前端 UI 交互与多轮讨论上下文一致性

### 产品经理

- 确认 HITL 审批弹窗交互方式（模态/内联、超时策略）
- 确认会话恢复流程（检测未完成 round 后的用户选项）
- 确认消息时间戳时区转换责任方
- 确认模型热切换时的 loading 状态提示方案

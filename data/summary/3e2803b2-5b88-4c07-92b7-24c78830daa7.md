## 一、会议纪要

## 用户需求
复刻开源项目 MeetMind（多 Agent RAG 协作系统），技术栈 LangChain + LangGraph + PostgreSQL(pgvector) + 本地 Reranker。

## 关键结论与决策
- **MVP 范围**：单轮对话 + 基础 RAG，后续迭代加多轮记忆和流式输出。
- **优先级**：US1 多角色 Agent 协作对话 > US2 RAG 混合检索 > US3 知识库管理。
- **前端技术选型**：React 18 + TypeScript + Vite + Zustand + Ant Design 5，工时约 8d。
- **后端技术选型**：LangGraph 五角色图编排 + pgvector 向量检索 + BGE-reranker-v2-m3 本地精排 + SSE 流式推送，工时约 10d。
- **鉴权方案**：MVP 阶段用 API Key（X-API-Key header）+ express-rate-limit 限流。
- **测试策略**：对话流完整性和 RAG 检索准确性为 P0 必须自动化；知识库写入和异常路径为 P1。

## 二、各 Agent 的工作

### 架构师

- 汇总全员发言，形成最终会议纪要。
- 跟进 PM 对三个待拍板问题的决策（Embedding 选型、多轮记忆是否入 MVP、Reranker 部署方式）。
- 后续在技术选型确定后，输出整体架构设计文档。

### 后端工程师

- 搭建项目骨架：DB migration + pgvector 扩展 + 基础 API 框架。
- 实现 LangGraph 五角色图编排（rewrite → intent → route → 5 角色依次执行）。
- 实现 RAG 管线：pgvector 向量检索（cosine 距离，IVFFlat 索引）+ BGE-reranker-v2-m3 本地精排。
- 实现 SSE 流式推送（event: node_update / message / done）。
- 实现知识库模块：文件上传 → 切片 → embedding 写入 pgvector。
- 实现鉴权（API Key）+ 限流（express-rate-limit）+ 异常处理。
- 等待 PM 确认 Embedding 模型选型、多轮记忆范围、Reranker 部署方式后调整方案。

### 前端工程师

- 搭建前端项目骨架：React 18 + TypeScript + Vite + Zustand + Ant Design 5。
- 实现对话页：SSE 流式渲染 + AgentFlowPanel 节点流转可视化 + MessageList（react-window 虚拟滚动）+ ChatInput。
- 实现知识库管理 CRUD：上传页、文档列表、文档详情 + 切片预览。
- 实现路由与布局：`/`、`/chat/:sessionId`、`/knowledge`、`/knowledge/upload`、`/knowledge/:docId`。
- 实现异常/空状态/loading 等边界 UI。
- 等待 PM 确认：节点动画过渡方案、是否加中断生成按钮、上传格式范围。

### 测试工程师

- 编写 P0 自动化用例：对话流完整性（5 角色不跳步不重复）、RAG 检索准确性（正确答案在 Top-3）。
- 编写 P1 用例：知识库写入（上传 PDF → 切片入库 → 检索命中）、异常路径（空输入/超长输入/无匹配意图/pgvector 不可用）。
- 验证 Reranker 本地模型一致性（固定 seed，对比不同环境分数漂移）。
- 验证 pgvector 索引类型（IVFFlat vs HNSW）对召回率的影响，确保测试与生产对齐。
- 预留多轮记忆状态污染测试点（为后续迭代做准备）。

## 一、会议纪要

用户要求复刻 GitHub 项目 MeetMind（多 Agent 协作系统），核心机制是五角色（architect/pm/backend/frontend/tester）串行讨论，产出比单模型直答更可靠的技术方案。

**关键结论与决策：**
- 复刻范围：五角色协作流程、意图路由（闲聊/知识问答→轻量助手，开发需求→团队讨论）、SSE 事件流、HITL 审批、会话管理、会议纪要生成、本地 RAG 检索
- 优先级：P0（MVP）→ P1（核心体验）→ P2（体验增强）
- 发言模式：严格串行，与原项目一致
- 工具审批超时：30 秒超时，默认拒绝
- 移动端：P0 不做响应式适配，仅桌面端
- 测试环境：Docker Compose 一键拉起（PostgreSQL + pgvector）
- 前端技术栈：React 18 + TypeScript + Vite + Ant Design 5 + Zustand（原项目为 Vue 3，用 React 重写）
- 总工时估算：26-34 人天（不含联调）

**待办事项：**
- 各角色按 P0 优先级启动开发，有阻塞问题随时同步

## 二、各 Agent 的工作

### 架构师

无

### 后端工程师

- P0：搭建 FastAPI 骨架 + JSON-RPC 统一入口（`POST /api`）
- P0：实现五角色 Agent 编排引擎核心循环（预处理管线 → Agent 节点 → 条件路由）
- P0：SSE 端点 `GET /events?sessionId=…`，推送 10 种事件类型
- P1：PostgreSQL + pgvector 持久化（sessions/messages/文档表 + LangGraph Checkpoint）
- P1：HITL 审批接口（工具风险分级，medium+ 暂停等待确认）
- P1：上下文压缩（`chat.compact`）与会议纪要生成（`chat.end`）
- P2：本地 RAG 混合检索管线（pg_trgm + pgvector → cross-encoder rerank）

### 前端工程师

- P0：搭建 React 18 + TypeScript + Vite + Ant Design 5 + Zustand 脚手架
- P0：SSE EventSource 消费模块，处理 turn_start/delta/turn_end/tool_approval_request/tool_result/summary_done 等事件
- P0：消息列表流式渲染（打字机效果）+ 会话管理侧边栏（新建/切换/删除）
- P1：HITL 审批弹窗（工具名/参数/风险等级展示，确认/拒绝操作，30s 超时提示）
- P1：会议纪要 Markdown 渲染面板 + 下载 .md 文件
- P2：意图路由可视化（轻量助手单气泡 vs 多角色串行讨论流）

### 测试工程师

- P0：搭建 Docker Compose 环境（PostgreSQL 16 + pgvector）+ 数据准备脚本
- P0：编写冒烟自动化用例（闲聊直答、开发需求触发协作、SSE 事件完整性、会话持久化恢复）
- P1：边界与异常场景覆盖（意图路由模糊输入/超长输入/空字符串、HITL 审批超时/连续拒绝/断线重连、Agent 迭代上限兜底、SSE 断线重连）
- P1：性能基准测试（首字节 <500ms、单轮 <15s、10 并发无事件串扰）
- P2：RAG 召回质量人工抽样评估、长期稳定性测试

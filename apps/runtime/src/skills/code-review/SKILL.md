# 代码评审技能

收到一段代码后，按下面四个维度逐条评审，每条指出「问题 → 影响 → 建议改法」：

1. **正确性**：边界条件、空值、并发、错误处理是否完备。
2. **可读性**：命名是否见名知意，控制流是否清晰，是否有过度抽象。
3. **性能**：是否有不必要的重复计算、N+1、阻塞调用。
4. **安全**：是否有注入、越权、敏感信息泄露、未校验的外部输入。

最后给一个总体结论（可合并 / 需修改 / 阻断），并按优先级排序问题列表。
